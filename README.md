# 记账本——个人财务管理系统

基于 B/S 架构的个人财务管理系统，支持多渠道收支管理、账户转账、预算提醒、数据可视化等功能。

## 技术栈

- **后端**：Python Flask 3.1
- **数据库**：SQLite 3（11 张数据表）
- **前端**：Bootstrap 5、Chart.js、Jinja2 模板引擎
- **架构**：三层 B/S 架构（表示层 / 业务逻辑层 / 数据访问层）

## 功能模块

用户管理、收支记录、账户管理、转账、分类标签、预算、统计图表、年度报告、周期性账单、提醒中心、回收站、批量操作、搜索增强、CSV 导出（共 14 个功能模块）。

## 核心特性

- 收支记录多条件筛选排序，账户余额自动计算
- 预算超支标红提醒，Chart.js 四种数据可视化（饼图/柱状图/折线图/日历热力图）
- 年度报告 Top10 消费排行，周期性账单自动生成
- 回收站 30 天软删除恢复，CSV 数据导出，深色模式切换
- PBKDF2 加盐哈希密码存储 + Session 会话鉴权
- SQL 多条件组合筛选与分页，软删除与事务处理保证数据一致性

## 运行方式

```bash
# 1. 安装依赖
pip install -r requirements.txt

# 2. 启动服务
python run_server.py
```

访问 http://127.0.0.1:5000
